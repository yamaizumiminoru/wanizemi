## TXTで相談する

1. 表から担当のTXTを保存します。ブラウザに本文が開いたら、ダウンロードボタンか「名前を付けて保存」を使ってください。
2. [ChatGPT](https://chatgpt.com/)で新しいチャットを開き、保存したTXTを添付します。無料プランでもファイルを添付できれば使えます。
3. 「このガイドに沿って」と書き、自分の相談を続けて送ります。論文や草稿を見てほしいときは、そのファイルも添付するか、見てほしい段落を貼り付けてください。

たとえば、粘着君のTXTと論文を添付したら、こんなふうに始められます。

> このガイドに沿って、粘着君として一緒に読んでください。第3節の3つの例から、結論で述べていることまで本当に言えますか？

続きは同じチャットで相談できます。新しいチャットで始めるときは、ガイドをもう一度添付してください。モデルを選べる場合は、その時点で自分のアカウントで使える最新世代をおすすめします。

## プラグインで相談する

Web版ChatGPTでプラグインをアップロードできる方は、表から担当のZIPを保存し、「プラグインをアップロード」でZIPのまま登録してください。新しいチャットで登録した担当を選ぶと、毎回ガイドを添付せずに相談できます。アップロードの項目が見当たらない場合は、同じ行のTXTで始められます。[OpenAIの操作案内](https://help.openai.com/ja-jp/articles/20001256-plugins-in-chatgpt)
